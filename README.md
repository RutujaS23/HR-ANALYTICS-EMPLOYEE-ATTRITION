# HR Analytics & Employee Attrition Analysis

## 📌 Project Overview

This project focuses on analyzing employee data to understand workforce distribution, salary trends, employee performance, and employee attrition.

The main objective is to identify factors contributing to employee attrition and generate meaningful business insights that can help organizations improve employee retention and workforce planning.

## 🎯 Project Objectives

- Analyze total employee headcount.
- Calculate department-wise and job-role-wise employee distribution.
- Analyze average annual salary across departments.
- Identify employee attrition rates.
- Understand attrition based on department, job role, and experience.
- Analyze employee performance and salary trends.
- Generate meaningful HR business insights.
